# Stakeholder und Systemkontext — Terminplaner für die THM



## Stakeholder



| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | sind diejenigen, die Termine buchen |
| Sekreteriat | Sie verwalten die Termine. Das heißt sie beeinflussen die Funktionsweise sowie das Aussehen |
| Lehrende | Sie bieten Termine an |
| Rechenzentrum | dort sind Ressorcen wie Server und Datenbank betrieben |
| KI-Agent | Personnen können durch den KI-Agenten Termine buchen |
| Screenreader | Bedienbarkeit der Buchungsseite |

## Systemkontext



| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| KI-Agent | System | Terminbuchung über KI sollte möglich sein |
| Sekretariat | Person | verwalten Termine |
| Studente | Person | können direkt Termin buchen |
| Lehrende | Person | können Termine anbieten |
| Rechenzentrum | Person | Auf seinen Server wird der Terminplaner betrieben |

## Irrelevante Umgebung



- Parking — keine Parkingplätze werden von Nutze sein
- Asta-Shop — es geht nicht um Verkaufsystem
