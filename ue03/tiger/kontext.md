# Stakeholder und Systemkontext — Terminplaner für die THM


## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie fordern eine einfache mobilre Bedieenung |
| Lehrende | Sie verlangen flexible Sprechzeiten |
| IT-Abteilung | Geben Regln für IT-Sicherheit vor |
| ASta | Interessenvertretung für Studierende |
| Prüfungsamt | Fordert die genaue Einhaltung von Fristen |
| Datenschutzbeauftragter | Sorgen dafür,dass Daten geschützt werden |

## Systemkontext


| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Moodle | System im Betrieb | Das System muss Termine an Moodle übertragen, damit Studierende sie direkt in ihren Kursen sehen |
| Uni-Account | System im Betrieb | Das System muss die Logins der THM erkennen, damit sich niemand neu anmelden muss.|
| Prüfungsordnung | Dokument | Das System muss die offiziellen Regeln und Fristen für Pflichttermine genau einhalten |
| Semsterferien | Ergeinis | Das System muss wissen, wann Ferien sind, um Sprechzeiten automatisch zu sperren |
| Bewerber | Person | Muss Termine für Bewerber anbieten |
