# Anforderungen — Terminplaner für die THM

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Studierende können freie Sprechstundentermine bei Lehrenden buchen. | Studierende | FA |
| A02 | Das System muss verhindern, dass zwei Studierende denselben Termin buchen. | Studierende | FA |
| A03 | Das System soll eine einfache und schnelle Terminbuchung ermöglichen. | Studierende | QA | 
| A04 | Das System soll 2.000 Studierende gleichzeitig unterstützen können. | Studierende | QA | 
| A05 | Studierende müssen eine VPN-Verbindung nutzen, wenn sie Termine außerhalb des Hochschul-WLANs buchen möchten. | Studierende |RB |
| A06 | Studierende müssen sich für die Terminbuchung mit ihrem THM-Konto anmelden. | Studierende | RB |
| A07 | Lehrende können ihre angeboten Sprechstundentermine änderen. | Lehrende | FA |
| A08 | Das System soll Terminbuchung auch an Feiertagen ermöglichen. | Studierende | FA |

## Eine Anforderung, die niemand ausgesprochen hat

Das System muss Studierende über eine erfolgriche Terminbuchung informieren. 
Begründung : Diese Anforderung wurde im Meeting nicht ausdrücklich erwähnt, weil es selbstverständlich erscheint, dass Studierende eine Bestätigung für ihre Buchung erhalten.
