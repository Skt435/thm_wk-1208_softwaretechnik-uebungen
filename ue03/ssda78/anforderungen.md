# Anforderungen — Terminplaner für die THM

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Studierende sollen freie Termine suchen können. | Studierende | FA |
| A02 | Studierende sollen verfügbare Termine buchen können. | Studierende | FA |
| A03 | Dozenten sollen eigene Termine anbieten können. | Dozenten | FA |
| A04 | Studierende sollen ihre gebuchten Termine einsehen können. | Studierende | FA |
| A05 | Das System soll innerhalb von drei Sekunden auf eine Terminsuche reagieren. | Studierende | QA |
| A06 | Das System soll nur für angemeldete Benutzer zugänglich sein. | IT-Administration | QA |
| A07 | Das System soll personenbezogene Daten vor unberechtigtem Zugriff schützen. | Hochschulverwaltung | QA |
| A08 | Eine Terminbuchung muss eindeutig einem Studierenden zugeordnet werden. | Sekretariat | RB |
| A09 | Ein Termin darf nicht gleichzeitig von mehreren Studierenden gebucht werden. | Dozenten | RB |

## Eine Anforderung, die niemand ausgesprochen hat

A07: Das System soll personenbezogene Daten vor unberechtigtem Zugriff schützen.

Diese Anforderung wurde möglicherweise nicht ausdrücklich genannt, weil Datenschutz als selbstverständlich angesehen wird. Trotzdem muss das System die persönlichen Daten der Studierenden schützen.
