# Stakeholder und Systemkontext — Terminplaner für die THM


## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |

| Studierende | Studierende benötigen eine einfache Möglichkeit, freie Termine bei Lehrenden zu finden |

| Lehrende | Lehrende legen ihre verfügbaren Zeitfenster fest, welche Termine wann gebucht werden können |

| Sekretariate | Sekretariate unterstüzeen Lehrende bei der Terminorganisation |

| Hochschulverwaltung | Die Hochschulverwaltung legt organisatorische Rahmenbedingungen fest |

| IT-Administration | Die IT-Administration verwaltet Benutzerkonten und Zugriffsrechte |

| Rechenzentrum der THM | Das Rechenzentrum ist für den technischen Betrieb und die Verfügbarkeit der IT-Infrastruktur verantwortlich |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |

| Studierende | Person | Nutzen den Terminplaner, um verfügbare Sprechstundentermine zu finden |

| Lehrende | Person | Stellen ihre verfügbaren Zeitfenster bereit |

| Hochschul-Login der THM | System im Betrieb | Muss die Anmeldung der Benutzer über das bestehende Authentifizierungssystem ermöglichen |

| Absage eines Termins | Ereignis | Kann dazu führen, dass ein Zeitfenster wieder freigegeben und für andere Personen buchbar wird |

| Vereinbarung einer Sprechstunde | Prozess | Umfasst die Auswahl eines freien Zeitfensters, die Buchung und die anschließende Bestätigung |

| Vorlesungs- und Prüfungszeiten | Dokument | Enthalten Informationen über Zeiträume, in denen Lehrende möglicherweise keine Sprechstunden anbieten können |

## Irrelevante Umgebung

1. Mensa der THM
Die Mensa gehört zwar zur Umgebung der THM, hat aber keinen direkten Einfluss auf die Funktionen des Terminplaners. Für die Buchung von Sprechstunden müssen keine Informationen über Speisepläne verarbeitet werden.

2. Hochschulsport der THM
Die Sportkurse und Trainingszeiten gehören nicht zum vorgesehenen Funktionsumfang des Terminplaners, da dieser ausschließlich zur Organisation von Sprechstundenterminen dient.
