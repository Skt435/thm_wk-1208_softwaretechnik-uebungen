# Anforderungen – Terminplaner für die THM

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Studierende müssen über das System Sprechstundentermine bei Lehrenden buchen können. | Studierende | FA |
| A02 | Studierende müssen ihre gebuchten Termine als iCal-Datei herunterladen können. | Studierende | FA |
| A03 | Sekretariate müssen eine Übersicht über die gebuchten Termine erhalten können. | Sekretariat | FA |
| A04 | Das System muss gebuchte Termine übersichtlich und verständlich darstellen. | Sekretariat | QA |
| A05 | Die Terminbuchung muss für Studierende einfach und ohne umfangreiche Einarbeitung möglich sein. | Studierende | QA |
| A06 | Das System muss zunächst ohne eine direkte Anbindung an bestehende Kalender funktionieren. | THM | RB |
| A07 | Das System muss zunächst ohne eine Anbindung an weitere externe Werkzeuge betrieben werden können. | THM | RB |
| A08 | Das System muss verhindern, dass derselbe Termin von mehreren Studierenden gleichzeitig gebucht wird. | Studierende und Lehrende | FA |

## Eine Anforderung, die niemand ausgesprochen hat

A08: Das System muss verhindern, dass derselbe Termin von mehreren Studierenden gleichzeitig gebucht wird.

Diese Anforderung wurde im Gespräch nicht ausdrücklich genannt, ist aber wichtig, damit es nicht zu Doppelbuchungen kommt. Dadurch wird sichergestellt, dass jeder Termin nur einmal vergeben wird und keine Überschneidungen entstehen.
