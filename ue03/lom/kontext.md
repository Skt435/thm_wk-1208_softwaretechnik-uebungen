## Stakeholder

<!-- Mindestens sechs Stakeholder, je mit einem Satz dazu, worauf sie
     Einfluss haben. -->

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie beeinflussen, wie freie Termine gesucht, gebucht und abgesagt werden können. |
| Lehrende | Sie beeinflussen, wie Sprechstunden und Prüfungstermine angeboten und verwaltet werden. |
| Sekretariate | Sie beeinflussen, welche Terminübersichten und Verwaltungsfunktionen benötigt werden. |
| Rechenzentrum der THM | Es beeinflusst die Anforderungen an Betrieb, Wartung und die Anbindung an das Hochschulkonto. |
| Datenschutzbeauftragte | Sie beeinflussen die Anforderungen zum Schutz und zur Verarbeitung personenbezogener Daten. |
| Hochschulleitung | Sie beeinflusst Budget, Projektziele und den Umfang der Einführung. |

## Systemkontext

<!-- Mindestens fünf Aspekte. Art: Person, System im Betrieb, Prozess,
     Ereignis oder Dokument. -->

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie suchen und buchen Termine über den Terminplaner und erhalten eine Bestätigung. |
| Lehrende | Person | Sie stellen verfügbare Zeiten bereit und verwalten ihre angebotenen Termine. |
| Hochschulweite Benutzerverwaltung | System im Betrieb | Sie überprüft die Hochschulkonten für die Anmeldung am Terminplaner. |
| Kalenderprogramme der Nutzenden | System im Betrieb | Sie übernehmen die vom Terminplaner bereitgestellten iCal-Dateien. |
| Externe KI-Agenten | System im Betrieb | Sie fragen über die API Termine ab und buchen diese im Auftrag berechtigter Personen. |

## Irrelevante Umgebung

- Mensaspeiseplan – Das Essensangebot wird für die Terminvereinbarung nicht benötigt.
- Bibliotheksausleihe – Die Ausleihe und Rückgabe von Büchern hat keine Verbindung zum beschriebenen Terminplaner.
