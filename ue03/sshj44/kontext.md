# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Suchfunktion, Buchungsfunktion |
| Lehrende | Erstellungsfunktion |
| Sekretariat | Organisations- u. Übersichtsfunktion |
| Prüfungsamt | Übersichtsfunktion |
| IT-Abteilung | Technische Anforderungen |
| DS-Beauftragte | Schutz pb. Daten |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Primäre Nutzer des Systems |
| Hochschulkonto/-portal | System im Betrieb | ID der Nutzer |
| Terminbestätigung | Prozess | Überprüfung des Slots bei Buchung |
| Prüfungsanmeldungsphase | Ereignis | Robuster Bau für konzentrierte Zugriffe |
| iCal | Dokument | Erstellung und Downloadoption bei Buchung |

## Irrelevante Umgebung

- Bibliothek — keinerlei Einfluss auf die Termine einzelner Studierenden/Lehrenden
- Mensa — technisch kein Einfluss auf die Termine einzelner Studierenden/Lehrenden
