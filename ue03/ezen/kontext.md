# Stakeholder und Systemkontext — Terminplaner für die THM



## Stakeholder


| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | beeinflussen, wie man Termine suchen und buchen kann |
| Professoren | beeinflussen, wie Sprechstundentermine angeboten werden |
| Mitarbeiter | beeinflussen, wie Termine vereibart werden können |
| Studienberatung | beeinflusst, wie Studieninteressierte Beratungstermine vereinbart werden |
| Prüfungsamt | beeinflusst, wie Termine für Fragen zu Klausuren vereinbart werden |
| IT- Abteilung | beeinflusst, wie Terminplaner technisch funktionieren soll |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | sie können dies nutzen um Termine zu buchen |
| Professoren | Person | sie bieten Termine an |
| Terminvereinbarung | Prozess | hilft dabei, Termine zu vereinbaren |
| Terminabsage | Ereignis | die Buchung wird dadurch geändert |
| Öffnungszeiten | Dokument | hilft passende Termine zu finden |
| Hochschul-Login | System im Betrieb | damit kann man sich anmelden |

## Irrelevante Umgebung

- Mensa — spielt bei Vereinbarung von Terminen keine Rolle
- Sportanlage — gehört auch nicht in einen Terminplaner
