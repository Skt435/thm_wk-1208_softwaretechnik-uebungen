
# Stakeholder und Systemkontext – Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie benötigen eine einfache Möglichkeit, Termine online zu buchen und zu stornieren. |
| Lehrende | Sie legen fest, wann sie Termine anbieten und wie viele Plätze verfügbar sind. |
| Sekretariate | Sie benötigen einen Überblick über Termine und Buchungen. |
| THM-IT-Abteilung | Sie stellt Anforderungen an die technische Sicherheit und die Anbindung an das Hochschulkonto. |
| Datenschutzbeauftragte | Sie achten darauf, dass personenbezogene Daten geschützt werden. |
| Hochschulleitung | Sie legt organisatorische Rahmenbedingungen und Ziele für den Einsatz des Terminplaners fest. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie buchen und verwalten Termine über das System. |
| Hochschulkonto | System im Betrieb | Es ermöglicht die Anmeldung und Identifizierung der Nutzer. |
| Hochschulkalender | System im Betrieb | Termine können in den Kalender übernommen werden. |
| Terminbuchung | Prozess | Bei der Buchung muss geprüft werden, ob der gewünschte Zeitraum frei ist. |
| Terminabsage | Ereignis | Eine Stornierung verändert die Verfügbarkeit und kann eine Benachrichtigung auslösen. |
| Terminbestätigung | Dokument | Sie enthält die wichtigsten Angaben zum gebuchten Termin. |

## Irrelevante Umgebung

- **Mensa-Speiseplan:** Die angebotenen Mahlzeiten haben keinen direkten Einfluss auf die Funktionen des Terminplaners.
- **Bibliotheksbestand:** Welche Bücher in der THM-Bibliothek vorhanden sind, ist für die Buchung von Sprechstunden und Prüfungsterminen nicht relevant.
