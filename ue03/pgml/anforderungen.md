# Anforderungen — Terminplaner für die THM

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Das System muss der Lehrkraft die Möglichkeit bieten, eine Abwesenheit mit Start- und Enddatum zu erfassen. | Lehrpersonen | FA |
| A02 | Das System muss alle Zeitfenster einer Lehrkraft, die in einen erfassten Abwesenheitszeitraum fallen, automatisch für Buchungen sperren. | Lehrpersonen | FA |
| A03 | Das System muss bei einer Verlängerung der Abwesenheit die zusätzlich betroffenen Zeitfenster sperren. | Lehrpersonen | FA |
| A04 | Das System muss während der Vorlesungszeit zu 99,9 % verfügbar sein. | Studierende und Lehrpersonen | QA |
| A05 | Das System muss eine Terminbuchung innerhalb von 3 Sekunden bestätigen. | Studierende | QA |
| A06 | Das System muss als Webanwendung umgesetzt werden. | Auftraggeber und Hochschule | RB |
| A07 | Die Projektdokumentation muss in deutscher Sprache erstellt werden. | Auftraggeber und Hochschule | RB |
| A08 | Das Entwicklungsteam besteht aus 4 Personen. | Projektleitung / Auftraggeber | RB |


## Eine Anforderung, die niemand ausgesprochen hat

A03: Diese Anforderung wurde nicht ausdrücklich genannt, weil die Stakeholder es als selbstverständlich ansehen, dass die Sperrung der Termine auch bei einer Verlängerung der Abwesenheit gilt.
