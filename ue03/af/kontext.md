# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Lehrende | Sie bestimmen, wie Sprechstunden-Slots angelegt, geändert und abgesagt werden. |
| Studierende | Sie bestimmen, wie einfach Termine gefunden, gebucht und storniert werden können. |
| Sekretariate der Fachbereiche | Sie beeinflussen, ob Termine stellvertretend für Lehrende verwaltet werden können. |
| Rechenzentrum der THM | Es gibt technische Vorgaben zu Betrieb, Anmeldung und IT-Sicherheit vor. |
| Datenschutzbeauftragter der THM | Er legt fest, welche personenbezogenen Daten gespeichert und wann sie gelöscht werden. |
| Personalrat | Er achtet darauf, dass das System nicht zur Leistungs- oder Verhaltenskontrolle der Lehrenden genutzt wird. |
| Beauftragter für Barrierefreiheit | Er fordert, dass das System auch mit Beeinträchtigungen bedienbar ist. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie buchen Termine im System, sind aber selbst nicht Teil davon. |
| THM-Login (Campus-Zugangsdaten) | System im Betrieb | Der Terminplaner nutzt ihn zur Anmeldung, betreibt ihn aber nicht selbst. |
| E-Mail-System der THM | System im Betrieb | Über das werden Buchungsbestätigungen und Absagen verschickt. |
| Kalender der Lehrenden | System im Betrieb | Sprechstunden dürfen nicht mit anderen Terminen der Lehrenden kollidieren. |
| Semesterbeginn | Ereignis | Zu Semesterbeginn legen Lehrende ihre neuen Sprechstunden an. |
| Ausfall einer/eines Lehrenden | Ereignis | Bei Krankheit müssen bereits gebuchte Termine abgesagt werden. |
| Datenschutzordnung der THM / DSGVO | Dokument | Sie gibt vor, wie mit den Daten der Buchenden umzugehen ist. |

## Irrelevante Umgebung

- Mensa-Speiseplan — hat keinen Bezug zu Sprechstunden oder Terminbuchungen.
- Bibliotheksausleihe — ist ein eigener Prozess, der keine Termine mit Lehrenden betrifft.
