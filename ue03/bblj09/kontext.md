# Stakeholder und Systemkontext – Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Lehrende | Sie bestimmen, welche Angaben und Abläufe sie zum Anbieten von Sprechstunden und Prüfungsterminen benötigen. |
| Studierende | Sie beeinflussen die Anforderungen an das Finden und Buchen von Terminen sowie an eine verständliche Bedienung. |
| Sekretariate | Sie bestimmen, welche Übersichten sie zur organisatorischen Betreuung der Termine benötigen. |
| Verantwortliche der THM | Sie klären Projektziele, Einführungstermin und Umfang eines möglichen Auftrags; ihre konkreten Vertreter sind noch offen. |
| Hochschul-IT (angenommen) | Sie beeinflusst die technischen und betrieblichen Vorgaben sowie die Anbindung an das Hochschulkonto. |
| Datenschutzverantwortliche der THM (angenommen) | Sie beeinflussen die Vorgaben zum Umgang mit personenbezogenen Termin- und Kontodaten. |

## Systemkontext

Das betrachtete System ist die neue Terminplaner-Software.
Personen, externe Systeme und organisatorische Abläufe,
mit denen sie zusammenwirkt, liegen außerhalb ihrer Systemgrenze.

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Lehrende | Person | Sie stellen Sprechstunden und Prüfungstermine im Terminplaner bereit. |
| Studierende | Person | Sie wählen angebotene Termine aus und buchen diese. |
| Sekretariate | Person | Sie nutzen den Terminplaner, um den Überblick über Termine zu behalten. |
| Hochschulkonto bzw. zugehöriger Anmeldedienst | System im Betrieb | Die Software soll über das Hochschulkonto nutzbar sein; die genaue Anbindung ist noch zu klären. |
| Kalenderprogramme der Beteiligten | System im Betrieb | Sie sollen die heruntergeladenen iCal-Dateien übernehmen können; eine direkte Eintragung ist erst eine mögliche spätere Erweiterung. |
| Heruntergeladene iCal-Datei | Dokument | Sie überträgt Termininformationen aus dem Terminplaner an die Kalenderprogramme. |
| Externe KI-Agenten | System im Betrieb | Sie sollen den Terminplaner über dessen API steuern können; die Agenten selbst gehören nicht zum Terminplaner. |
| Vereinbarung von Sprechstunden und Prüfungsterminen | Prozess | Diesen organisatorischen Ablauf soll die neue Software unterstützen. |

## Irrelevante Umgebung

- Mensaspeisepläne: Für die beschriebenen Funktionen zur Terminplanung ist keine Wechselwirkung mit Speiseplänen erkennbar.
- Bibliotheksausleihe: Das Ausleihen und Zurückgeben von Medien gehört nicht zum beschriebenen Zweck des Terminplaners.

Diese Abgrenzung gilt für den aktuell beschriebenen Umfang.
Falls weitere Anforderungen hinzukommen, muss sie erneut geprüft werden.
