# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie buchen Sprechstundentermine |
| Professoren | Sie legen fest, wann sie Sprechstunden anbieten | 
| Sekretariat | Sie unterstützen bei der Verwatltung der Termine |
| THM-Rechenzentrum | Es sorgt dafür, dass das System technisch funktioniert |
| Hochschulleitung | Sie legt Regeln für den Terminplaner fest |
| Datenschutzbeautragte | Sie achten darauf, dass persönliche Daten geschützt sind |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie nutzen den Terminplaner, um Termine zu buchen |
| Professoren | Person | Sie bieten Sprechstundentermine an | 
| Hochschulkonto | System im Betrieb | Es wird für die Anmeldung benötigt |
| Sprechstunde | Prozess | Dabei findet das Gespräch zwischen Studiereneden und Professoren statt | 
| Absage einer Sprechstunde | Ereignis | Eine Absage kann Änderungen an gebuchten Terminen notwendig machen | 

## Irrelevante Umgebung

- Mensa — Sie hat nichts mit der Buchung von Sprechstundenterminen zu tun
- Bibliothek — Ihre Ausleihverwaltung grhört nicht zum Terminplaner
