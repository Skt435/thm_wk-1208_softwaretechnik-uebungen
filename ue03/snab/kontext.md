# Stakeholder und Systemkontext — Terminplaner für die THM



## Stakeholder



| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Lehrende | Bestimmen die Funktionalitäten für die Terminvergabe. |
| Studierende | Beeinflussen die Anforderungen der Nutzbarkeit. |
| Sekretariat | Beeinflussen die Verwaltung von Räumen und Terminen im Auftrag von Lehrenden. |
| Administrator | Beeinflusst Anforderungen an Benutzerverwaltung und Rechtevergabe. |
| Datenschutzbeauftrager | Stellt Anforderungen an die DSGVO-Konformität. |
| IT-Service | Legt die technischen Vorgaben vor. |

## Systemkontext



| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| THM-Identity-Provider | System im Betrieb | Der Terminplaner muss dieses System nutzen, um Benutzer sicher zu authentifizieren. |
| Prüfungs- und Vorlesungsfreie Zeiten | Dokument | Das System muss die offiziellen Vorlesungs- und Prüfungszeiträume kennen, um passende Terminfenster vorzuschlagen |
| Webseite | System im Betrieb | Der Terminplaner läuft als Webanwendung und muss auf gängigen Browsern korrekt dargestellt und bedienbar sein. |
| E-Mail-Server der THM | System im Betrieb | Das System muss über den Mailserver essenzielle Informationen versenden. |
| Kalender der Lehrenden | System im Betrieb | Der Terminplaner muss Termine in externe Kalender exportieren oder abgleichen, um Doppelbuchungen zu vermeiden. |

## Irrelevante Umgebung



- Mensa-Speiseplan der THM — Der Mensa-Speiseplan hat keine Auswirkungen auf die Organisation des Terminplaners.
- Buchungssystem der Bibliothek — Das Buchungssystem der Bibliothek hat keine Auswirkungen auf die Organisation des Terminplaners.
