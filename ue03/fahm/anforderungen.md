# Anforderungen — Terminplaner für die THM

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Studierende können freie Sprechstundentermine suchen und buchen. | Studierende | FA |
| A02 | Lehrende können angebotene Sprechstundentermine erstellen und bearbeiten. | Lehrende | FA |
| A03 | Studierende können eine bereits gebuchte Buchung stornieren. | Studierende | FA |
| A04 | Das System zeigt angeforderte Termine innerhalb von zwei Sekunden an. | Studierende | QA |
| A05 | Die Buchungsseite ist auch ohne Maus mit der Tastatur bedienbar. | Studierende | QA |
| A06 | Das System verhindert, dass zwei Personen denselben Termin gleichzeitig buchen. | Lehrende | QA |
| A07 | Die Anmeldung am Terminplaner erfolgt über das Hochschulkonto der THM. | Rechenzentrum der THM | RB |
| A08 | Personenbezogene Daten müssen entsprechend den geltenden Datenschutzvorgaben verarbeitet werden. | Datenschutzbeauftragte der THM | RB |

## Eine Anforderung, die niemand ausgesprochen hat

**Anforderung:** Studierende müssen automatisch informiert werden, wenn eine Lehrperson einen bereits gebuchten Termin absagt.

**Begründung:** Ohne eine solche Benachrichtigung könnten Studierende unnötig zum vereinbarten Termin erscheinen. Diese Anforderung wurde möglicherweise nicht ausdrücklich genannt, weil die Beteiligten davon ausgehen, dass Terminänderungen automatisch mitgeteilt werden.
