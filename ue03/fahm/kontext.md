# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie brauchen eine einfache Möglichkeit, freie Termine zu finden und zu buchen. |
| Lehrende | Sie legen fest, wann sie Sprechstunden anbieten und welche Termine verfügbar sind. |
| Sekretariat | Es organisiert Termine und braucht einen guten Überblick über die Termine des Fachbereichs. |
| Rechenzentrum der THM | Es kümmert sich darum, dass das System zuverlässig läuft und die Daten geschützt sind. |
| Hochschulleitung | Sie gibt die allgemeinen Ziele und organisatorischen Regeln für den Terminplaner vor. |
| Datenschutzbeauftragte der THM | Sie achten darauf, dass persönliche Daten korrekt und sicher verarbeitet werden. |
| Prüfungsamt | Es benötigt eine passende Möglichkeit, Prüfungstermine zu planen und zu verwalten. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie verwenden den Terminplaner, um freie Termine zu finden und zu buchen. |
| Lehrende | Person | Sie stellen ihre freien Zeiten für Sprechstunden zur Verfügung. |
| Hochschulkonto | System im Betrieb | Es kann für die Anmeldung am Terminplaner verwendet werden. |
| Prüfungsordnung | Dokument | Sie enthält Regeln, die bei der Planung von Prüfungsterminen wichtig sein können. |
| Absage einer Sprechstunde | Ereignis | Wenn eine Sprechstunde abgesagt wird, müssen bereits angemeldete Personen eventuell informiert werden. |
| Prüfungsanmeldung | Prozess | Während der Prüfungsanmeldung könnten viele Studierende gleichzeitig Termine benötigen. |

## Irrelevante Umgebung

- Mensa-Speiseplan — Er ist für die Buchung und Verwaltung von Terminen nicht wichtig.
- Parkplatzbelegung auf dem Campus — Ob Parkplätze frei sind, hat keinen direkten Einfluss auf die Terminbuchung.
