# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie beeinflussen die Anforderungen an die Suche, Auswahl und Buchung von Terminen. |
| Lehrende | Sie beeinflussen die Anforderungen daran, wie freie Termine angeboten und verwaltet werden. |
| Sekretariate | Sie beeinflussen die Anforderungen an die Verwaltung und Übersicht der Termine. |
| Prüfungsamt | Es beeinflusst die Anforderungen an die Verwaltung und Organisation von Prüfungsterminen. |
| THM-Rechenzentrum | Es beeinflusst die Anforderungen an Anmeldung, technischen Betrieb und Verfügbarkeit des Systems. |
| Datenschutzbeauftragte der THM | Sie beeinflussen die Anforderungen an den Schutz und die Verarbeitung personenbezogener Daten. |
| Hochschulleitung | Sie beeinflusst organisatorische Anforderungen und den hochschulweiten Einsatz des Terminplaners. |
| KI-Agenten | Sie beeinflussen die Anforderungen an die API und daran, welche Aktionen automatisiert ausgeführt werden dürfen. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie nutzen den Terminplaner, um freie Termine zu suchen und zu buchen. |
| Lehrende | Person | Sie stellen freie Termine bereit und verwalten ihre Termine. |
| THM-Hochschulkonto | System im Betrieb | Der Terminplaner soll die Anmeldung über das bestehende Hochschulkonto ermöglichen. |
| THM-Kalendersystem | System im Betrieb | Gebuchte Termine sollen mit den Kalendern der Beteiligten ausgetauscht werden können. |
| Terminbuchung | Prozess | Der Terminplaner muss den Ablauf vom Auswählen eines freien Termins bis zur bestätigten Buchung unterstützen. |
| Terminabsage | Prozess | Der Terminplaner muss ermöglichen, dass gebuchte Termine wieder abgesagt werden können. |
| iCal-Datei | Dokument | Nach einer Buchung soll ein Termin als iCal-Datei heruntergeladen und in einen Kalender übernommen werden können. |

## Irrelevante Umgebung

- Bibliothekssystem der THM — Die Verwaltung von Büchern und Ausleihen hat keine Bedeutung für die Funktionen des Terminplaners.
- Mensa der THM — Die Essensversorgung der Hochschule hat keinen Einfluss auf die Terminplanung.
