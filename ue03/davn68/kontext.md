# Stakeholder und Systemkontext — Terminplaner für die THM


## Stakeholder



| Stakeholder | Worauf hat er Einfluss? |
| --- | --- |
| Studierende | Sie buchen die Termine. |
| Prof. | Sie stellen Termine zur Verfügung. |
| Sekretariat | Die Laden die neuesten Informationen hoch. |
| Prüfungsamt | Die kontrollieren die Einhaltung der Termine. |
| IT-Support | Sorgt für die Flüssigkeit des Systems. |
| Studienbeauftragte | Plant Termine mit Studenten. |


## Systemkontext


| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie buchen freie Termine. |
| Prof. | Person | Sie stellen freie Termine zur Verfügung. |
| THM Login System | System im Betrieb | Sie prüft ob die Anmeldedaten in Ordnung sind. |
| THM E-Mail System | System im Betrieb | Schickt die Bestätigungen für Termine. |
| Kalender | System im Betrieb | Zeigt die gebuchten Termine an. | 

## Irrelevante Umgebung


- **Mensa:** *Hat keinen Einfluss auf das Buchen von Terminen.*
- **Bibliothek:** *Spielt keine Rolle, da es nicht für Termine benutzt wird.*
