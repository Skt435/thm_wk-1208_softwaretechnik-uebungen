# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Nutzen das System, um Sprechstunden und Prüfungstermine zu buchen und zu verwalten. |
| Lehrende | Bieten freie Zeiten und Sprechstunden an und verwalten eingehende Buchungen. |
| Studiensekretariat | Gibt offizielle Rahmenfristen und organisatorische Vorgaben vor. |
| IT-Abteilung / Rechenzentrum | Verwalten den sicheren Betrieb, Datenschutz und die Authentifizierung. |
| Hochschulleitung | Bestimmt übergeordnete Richtlinien für Lehre und digitale Prozesse. |
| Fachschaften | Vertreten die Studierendenperspektive hinsichtlich der Bedienbarkeit. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Zentrale Benutzerverwaltung (LDAP) | System im Betrieb | Das System muss bestehende THM-Zugangsdaten zur Anmeldung nutzen. |
| Offizielle Prüfungsordnungen | Dokument | Fristen und Rahmenbedingungen müssen eingehalten werden. |
| E-Mail-Server der THM | System im Betrieb | Das System muss automatische Benachrichtigungen versenden. |
| Vorlesungszeiten | Ereignis | Der Kalender muss sich an den offiziellen Vorlesungs- und Prüfungsphasen orientieren. |
| Raumplanungssoftware | System im Betrieb | Es muss eine Abstimmung über verfügbare Räume stattfinden. |

## Irrelevante Umgebung

- Mensa-Speiseplan / Campus-Catering: Betrifft den studentischen Alltag, hat aber keinen Einfluss auf die Terminvereinbarung mit Lehrenden.
- Ausleihsystem der Hochschulbibliothek: Die Medienverwaltung ist ein eigenständiger Prozess ohne Bezug zur Sprechstundenplanung.
