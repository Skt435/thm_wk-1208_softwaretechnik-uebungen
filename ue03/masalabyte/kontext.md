# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie bestimmen, wie einfach und verständlich die Bedienung sein muss, weil sie die Termine Sprechsstunden am Ende buchen wollen. |
| Dozenten | Sie legen fest, welche Einstellungen für freie Zeiten, Teilnehmeranzahlen und Absagen möglich sind. | 
| Fachbereichsverwaltung | Sie haben Einfluss auf , Datenschutzregeln, interne Vorgaben und Einhaltung der organisatorische Rahmenbedingunngen. |
| IT-Abteilung | Sie geben vor, wie sicher das System sein muss, welche Technik genutzt wird und wie der LOGIN (z.B. über den Hochschulkonto) funktioniert. |
| Studierendenvertretung(ASta) | Sie setzen sich dafür ein, dass die Plattform für alle gut bedienbar ist und niemand benachteiligt wird. |
| Stunden - und Raumplanungsverantwortliche | Sie sind dafür zuständig, dasss die gebuchten Termine nicht im Widerspruch zu den echten Vorlesungen oder Raumbelegungen stehen. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| zentraler Identity Provider | System im Betrieb | Das System muss prüfen, wer sich einloggt, übernimmt diese Nutzerverwaltung aber nicht selbst, sondern nutzt den Dienst der Hochschule |
| Prüfungsordnung der Studiengänge | Dokument | Darin stehen Fristen und Regeln, die man bei der Vergabe von bestimmten Terminen (wie Prüfungseinsichten) beachten muss. |
| Hochschul WLAN | System im Betrieb | Das neue System braucht natürlich eine stabile Internetverbindung, stellt diese aber selbst nicht zur Verfügung. |
| Semesterstart und Vorlesungsbeginn | Ereignis | Zu Semesterbeginn wollen auf einmal alle Studierenden gleichzeitig alle Termine buchen, worauf das System ausgelegt sein muss |
| THM Webmail | System im Betrieb | Bestätigungen und Erinnerungen sollen per Mail verschickt werden; das System greift dafür auf den THM-Mailserver zu, betreibt diesen aber nicht selbst. |

## Irrelevante Umgebung

- Die Mensa-Kasse — Die Kasse der Mensa hat keinerlei Berührungspunkte mit der Organisation von Sprechstunden oder Uni-Terminen.
- Ausleihsystem der Hochschulbibliothek — Das Buchen von Büchern läuft über ein komplett anderes Sysrem und spielt für den Terminplaner keine Rolle.
