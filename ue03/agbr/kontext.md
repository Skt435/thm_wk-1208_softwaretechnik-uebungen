## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Beeinflussen, wie einfach die Terminbuchung sein muss. |
| Professoren | Sie legen fest, wann sie Sprechstunden anbieten. |
| Sekretariat | Es kümmert sich um die Übersicht der Termine. |
| IT-Abteilung | Sie sorgen dafür, dass das System funktioniert. |
| Datenschutzbeauftragte | Sie achtet darauf, dass persönliche Daten geschützt sind. |
| Hochschulleitung | Sie entscheidet, ob das System eingeführt wird. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie buchen die Termine. |
| Hochschul-Login | System im Betrieb | Darüber können sich Nutzer anmelden. |
| Terminbuchung | Prozess | Hier werden die Termine gebucht. |
| Terminabsage | Ereignis | Ein Termin kann auch ausfallen. |
| Datenschutzregeln | Dokument | Persönliche Daten müssen geschützt werden. |

## Irrelevante Umgebung

- Mensa – Hat nichts mit den Sprechstundenterminen zu tun.
- Hochschulsport – Wird für die Terminbuchung nicht gebraucht.
