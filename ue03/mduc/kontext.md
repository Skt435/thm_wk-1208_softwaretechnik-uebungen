# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Sie wollen Termine schnell und einfach buchen. |
| Lehrende | Sie wollen Termine einfach anbieten und absagen können. |
| Sekretariate | Sie wollen einen Überblick über alle Termine ihres Fachbereichs. |
| Hochschulleitung | Sie bezahlt das Projekt und entscheidet, was umgesetzt wird. |
| Rechenzentrum | Es betreibt das System und gibt die Anmeldung über das Hochschulkonto vor. |
| Datenschutzbeauftragte | Sie legt fest, welche persönlichen Daten gespeichert werden dürfen. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende und Lehrende | Person | Sie benutzen das System, sind aber nicht Teil davon. |
| Hochschulkonto | System im Betrieb | Darüber melden sich alle an, es gibt es aber schon. |
| Kalenderprogramme (z. B. Outlook) | System im Betrieb | Sie müssen die iCal-Dateien öffnen können. |
| Prüfungsanmeldung | Ereignis | Dann buchen sehr viele gleichzeitig. |
| EU-DSGVO | Dokument | Sie regelt den Umgang mit persönlichen Daten. |

## Irrelevante Umgebung

- Mensa — hat nichts mit Terminen zu tun.
- Bibliothek — der Terminplaner braucht nichts von ihr.
