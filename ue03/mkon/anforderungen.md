# Anforderungen — Terminplaner für die THM

 Je Zeile eine
     Anforderung in einem Satz, dazu der Stakeholder, von dem sie stammt,
     und die Art: FA, QA oder RB. Mindestens acht Anforderungen, davon
     mindestens zwei je Art; die Nummern laufen A01, A02 … 

| Nr. | Anforderung | Stakeholder | Art |
|---|---|---|---|
| A01 | Das System muss eine Anmeldung über das Hochschulkonto ermöglichen.  |Sekretariat |FA |
| A02 | Bestätigungszusendung bei Annahme des Professors für die Terminanfrage. |Student  | FA |
| A03 | Die Terminübersicht soll auf einem Blick erkennbar sein. | Sekretariat | QA |
| A04 | Die Termindaten sollen vor Externen benutzern Anonym bleiben. | Student | QA |
| A05 | Personenbezogene Daten müssen der DSGVO entsprechen. | Verwaltung | RB|
| A06 | Datum der zur Verfügungstellung des Terminplaners.| IT-Techniker | RB |
| A07 | Benachrichtigung bei einer Terminanfrage.| Professor| FA |
| A08 | Die Bedienung soll einfach und verständlich sein.| Verwaltung | QA |
