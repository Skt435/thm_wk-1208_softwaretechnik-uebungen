# Stakeholder und Systemkontext — Terminplaner für die THM

## Stakeholder

| Stakeholder | Worauf hat er Einfluss? |
|---|---|
| Studierende | Wollen schnell und einfach Termine buchen. |
| Lehrende | Geben an, wann sie Zeit haben. |
| Sekretariat | Hilft bei Terminen und Fragen. |
| IT-Abteilung | Sorgt dafür, dass alles funktioniert. |
| Hochschulleitung | Entscheidet, was das System können soll. |
| Datenschutz | Achtet darauf, dass Daten sicher sind. |

## Systemkontext

| Aspekt | Art | Warum gehört er zum Kontext? |
|---|---|---|
| Studierende | Person | Sie buchen die Termine. |
| THM-Login | System im Betrieb | Man meldet sich mit seinem THM-Konto an. |
| THM-Kalender | System im Betrieb | Die Termine sollen dort angezeigt werden. |
| Prüfungsanmeldung | Prozess | Dann buchen sehr viele Leute gleichzeitig. |
| Semesterbeginn | Ereignis | Es können neue Termine dazukommen. |
| Datenschutzregeln | Dokument | Persönliche Daten müssen geschützt werden. |

## Irrelevante Umgebung

- Mensa — Hat mit der Terminbuchung nichts zu tun.
- Bibliothek — Wird für die Termine nicht benötigt.
